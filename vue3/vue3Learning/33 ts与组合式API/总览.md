# TypeScript 与组合式 API

## 为组件的 props 标注类型

### 使用 `<script setup>`

`defineProps()` 宏函数支持从它的参数中推导出类型

运行时声明

```vue
<script setup lang="ts">
const props = defineProps({
  foo: {
    type: String,
    required: true,
    default: '1',
    validator: (value) => {
      return value.length >= 1;
    },
  },
  bar: Number,
});
props.foo; // string 类型，会自动的推导出类型
props.bar; // number | undefined 类型
</script>
```

基于类型的声明（编译时声明）

```vue
<script setup lang="ts">
interface Props {
  foo: string;
  bar?: number;
}
const props = defineProps<Props>();

props.foo; // string 类型
props.bar; // number | undefined 类型
</script>
```

基于类型声明如果要进行默认值的话，要借助 `withDefaults()` 宏来进行设置
基于类型声明无法对传入的 props 进行校验

#### Props 解构默认值

在 3.5 版本

```vue
<script setup lang="ts">
interface Props {
  msg?: string;
  names?: string[];
}
const { msg = 'default', names = ['default'] } = defineProps<Props>();
</script>
```

3.4 及其以前版本

```vue
<script setup lang="ts">
interface Props {
  msg?: string;
  names?: string[];
}
const props = withDefaults(defineProps<Props>(), {
  msg: 'default',
  names: () => ['default'], // 注意这里要用工厂函数的方式
});
</script>
```

### 非 `<script setup>` 场景下

如果没有使用 `<script setup>`，为了开启 `props` 的类型推导，必须使用 `defineComponent()`，传入 `setup()` 的 `props` 对象类型是从 `props` 选项中推导出来的

```vue
<script lang="ts">
import { defineComponent } from 'vue';
export default defineComponent({
  props: {
    msg: {
      type: String,
      required: true,
      default: '1',
      validator: (value) => {
        return value.length >= 1;
      },
    },
  },
  setup(props) {
    // 这里的 props 的类型是从上面的 props 选项推导出来的
    props.msg; // string 类型，根据上方的 props 选项推导出来
  },
});
</script>
```

### 复杂的 props 类型

运行时声明，我们可以使用 `PropType` 工具

```vue
<script setup lang="ts">
import type { PropType } from 'vue';
interface Person {
  name: string;
  age: number;
}
const props = defineProps({
  person: Object as PropType<Person>,
});
</script>
```

## 为组件的 emits 标注类型

在 `<script setup>` 中，`emit` 函数的标注类型也可以通过运行时声明或类型声明进行

```vue
<script setup lang="ts">
// 运行时声明
const emit = defineEmits({
  changeData: (data: string) => {
    // 可以对参数进行校验，返回 true 表明校验成功
  },
});

// 类型声明
const emit1 = defineEmits<{
  (e: 'changeData1', data: string): void;
}>();
// 3.3+ 的版本
const emit2 = defineEmits<{
  changData1: [data: string];
}>();
</script>
```

非 `<script setup>` 环境中，使用 `defineComponent()` 可以根据 `emits` 选项推导出暴露在 setup 上下文中的 `emit` 的类型

```vue
<script>
import { defineComponent } from 'vue';
export default defineComponent({
  emits: {
    changeData1: (data: string) => true,
  },
  setup(props, ctx) {
    ctx.emit('changeData1', ''); // 这里会根据前面 emits 选项进行类型推导
  },
});
</script>
```

## 为 ref() 标注类型

ref 会自动的根据初始化的值进行类型推导
如果要进行复杂的类型指定，可以使用 `Ref` 工具类型，或者在调用 `ref()` 的时候传入泛型参数
如果指定了泛型参数，但是没有初始化的时候，会自动的添加 `undefined` 类型进行联合

```vue
<script setup lang="ts">
import { ref } from 'vue';
import type { Ref } from 'vue';

const data1 = ref(1); // number 类型
const data2: Ref<string | number> = ref(1);
const data3 = ref<string | number>('1');
const data4 = ref<number>(); // number | undefined 类型
</script>
```

## 为 reactive() 标注类型

- 自动推导
- 直接标注类型（不推荐使用 `reactive()` 的泛型参数）

```vue
<script setup lang="ts">
import { reactive } from 'vue';
const data1 = reactive({ name: '' }); // { name: string } 类型

interface Person {
  name: string;
  age: number;
}
const data2: Person = reactive({ name: '' });
</script>
```

## 为 `computed()` 标注类型

- 自动推导
- 泛型参数
- `ComputedRef<T>` / `WritableComputedRef<T>` 很少有场景使用，例如：一个函数的返回值是一个 computed，就可以使用这两个工具类型来标注

```vue
<script setup lang="ts">
import { computed, ref } from 'vue';
const count = ref<number>(0);
const data1 = computed(() => count.value * 2); // ComputedRef<number> 类型

const data2 = computed<number>(() => count.value * 2); // ComputedRef<number> 类型

const data3 = (count: number): ComputedRef(number) => {
  return computed(() => count * 2)
};
</script>
```

## 为事件处理函数标注类型

指的是为事件处理函数的参数进行类型标注

```vue
<script setup lang="ts">
const inputHandler = (e: Event) => {
  (e.target as HTMLInputElement).value;
};
</script>
<template>
  <input @input="inputHandler" />
</template>
```

## 为 provide / inject 标注类型

Vue 提供了一个 `InjectionKey` 接口，继承自 `Symbol` 的泛型函数

```ts
import type { injectionKey, Ref } from 'vue';

export const key = Symbol().for('key') as InjectionKey<Ref<number>>;
```

```vue
<script setup lang="ts">
import { provide } from 'vue';
import { key } from '';

const count: Ref<number> = ref(0);

provide(key, count); // 这里的 key，限制 provide 的值的类型只能是 Ref<number>
</script>
```

```vue
<script setup lang="ts">
import { inject } from 'vue';
import { key } from '';

const count = inject(key); // Ref<number> | undefined
</script>
```

## 为模板引用标注类型

- ref
- useTemplateRef

```vue
<template>
  <div>
    <input ref="inputRef" />
    <button ref="buttonRef">按钮</button>
  </div>
</template>

<script setup lang="ts">
import { ref, useTemplateRef } from 'vue';
import type { Ref } from 'vue';

const inputRef: Ref<HTMLInputElement | null> = ref(null);

const buttonRef = useTemplateRef<HTMLButtonElement>('buttonRef');
</script>
```

## 为组件模板引用标注类型

先使用 `typeof` 获取组件的类型，再使用 `InstanceType` 获取类型的实例类型

```vue
<template>
  <Component1 ref="component1Ref"></Component1>
</template>
<script setup lang="ts">
import Component1 from '';
import { useTemplateRef } from 'vue';

const component1Ref =
  useTemplateRef<InstanceType<typeof Component1>>('component1Ref');
</script>
```
